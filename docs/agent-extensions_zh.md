# Agent 扩展操作说明 — 川序 v4.5.1

本说明适用于社区版和企业版。身份、授权、确切版本、来源血缘、尝试、租约和
审计仍由数据库实体承载。配置集成不产生权限。启动新工作进程前安装并验证到
迁移 99 的完整追加迁移链；实际脚本以发行包生成的基线清单为准。

## 模型能力与回答质量

从 Dashboard「平台配置 → Agent 扩展」选择已配置的模型服务，分别执行文本、
流式、结构化输出、工具提案、推理参数、用量、图片输入和客户端取消探测。
结果绑定服务配置的确切修订；更改配置后重新探测。参数批准必须引用相同修订
的有效证据，不能向所有服务统一加入某种推理参数。隐藏推理正文不作为可见回答。
取消时区分客户端关闭连接与模型服务确认停止计算。

Portal 和频道共用知识检索与回答准备流程。未命中的模型回答、部分命中的补充
有独立来源说明；公司、数据库和供应商品牌等歧义问题先澄清。回答质量用例与
结果保存入口类型、用例与模型修订、策略摘要和获准引用，不沿用旧配置的结果。

## 工具、技能与上下文

先在当前授权域内检索工具或技能的名称、版本和摘要，再加载所选确切版本的正文。
目录搜索不授予调用权限。API 使用 `GET /api/agent-extensions/directory` 和
`POST /api/agent-extensions/directory/load`；加载与使用都重新核对当前主体、域、
原凭据、版本和资源权限。

对已有连续性上下文组装先计算预算，再创建派生内容。保守的 UTF-8 字节上界为
输出与指令预留空间；提取保留约束、决定与未完成事项原文，预算不足则拒绝。
读取派生内容时重新核对所有原始来源、摘要、域权限和组装有效期，来源撤销后
不能通过旧派生内容继续读取。

## 图工程

SLO 检查支持授权过滤、游标分页和状态筛选。清单预览检查大小、深度、schema
与登记执行器，返回预览摘要；按相同摘要导入草稿，不自动发布或执行。
检查点分叉需要确切当前检查点、原因和幂等键，保留血缘、预算与围栏；不确定的
外部副作用进入人工复核，不能盲目重复。

离线回放重建已提交状态，对比事件与检查点摘要；迁移预检比较确切源/目标版本、
稳定节点映射、待处理节点、租约、schema、预算和补偿要求。两者返回诊断结果，
不调用外部执行器，也不变更正在运行的图任务。

## 已登记集成

每个端点独立登记安全域、协议、确切版本、超时、响应大小上限和原因。远程服务
使用 HTTPS 与专用凭据。凭据加密保存，发现、执行和撤销都核对当前授权；协议
版本与 SDK 版本分别记录。

| 集成 | 本版支持的流程 |
|---|---|
| MCP | Streamable HTTP 2025-06-18 / 2025-11-25；有限分页发现、确切只读工具/schema 的独立批准、认证调用、取消与不确定发送对账。 |
| A2A | 有界 HTTP JSON 1.0.1 任务，绑定获准的图版本与编译计划；提交、检查、分页、恢复和取消，任务/图运行映射持久化。 |
| OTLP | 登记的 OTLP/HTTP JSON 1.9.0 接收端；仅发送已提交轨迹的元数据，保存投递尝试、有限重试和接收证据，不包含提示词和回答正文。 |
| 框架 | 仅固定 LangGraph 1.2.12；使用包内摘要锁定的依赖和经验证的不可变 Linux 根文件系统，完成事实须有独立隔离进程证据。 |

MCP 发现不批准执行；再次发现会关闭原批准，复核后重新批准。不确定发送先对账，
不自动重发。A2A 保留原凭据与图授权，和数据库派发机制 DB4A2A 分别验收。

通过服务管理器运行 `scripts/agent_integration_worker.py`，投递登记遥测并对账
不确定调用。使用 `scripts/prepare_framework_rootfs.py --rootfs
/var/lib/chuanxu/framework-v4.5.1` 准备新框架根文件系统，然后配置经验证的
Linux 隔离目标。框架只接收有界消息，数据库仍是执行状态与授权的事实源。
新版 MCP 协商和 `server/discover`、任意框架运行、真实副作用回放、运行中迁移与
全局自治仍不开放。

## 受管输入、进度与诊断

在有权安全域上传自己拥有的图片或文档。解析器支持 PNG/JPEG、UTF-8
纯文本/Markdown 和可提取文字的 PDF，文件上限为 4 MiB；图片另需当前模型修订通过
`IMAGE_INPUT` 探测。查询使用已获准的有效模型，保存输入/输出摘要和状态。
撤销后停止后续读取与使用。文档内容是不可信数据，不构成工具指令或授权；
不支持扫描 PDF 的 OCR 或任意音视频。

执行进度显示数据库状态、排队/首 Token 延迟和取消结果。只读诊断须明确触发，
可检查能力、Agent 或模型服务并保存脱敏结果，不自动修复配置或启动全局自治。
远端结果尚未确认时，保留「未观测」与「失败」「已取消」的区别。
