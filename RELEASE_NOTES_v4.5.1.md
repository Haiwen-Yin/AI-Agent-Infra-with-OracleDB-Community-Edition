# Chuanxu v4.5.1

Date: 2026-10-06

## Changes

- Improve desktop navigation, channel forms, searchable member selection and
  the original Chuanxu wordmark.
- Render searchable Principal candidates in an anchored, bounded overlay so
  opening, paging or refreshing the list does not move following form fields;
  retain keyboard, pagination and exact-ID behavior.
- Bind independent Provider capability probes and supported reasoning parameters
  to the exact model configuration revision. Health checks require a nonempty
  answer from the selected model.
- Add authorized Tool/Skill discovery and exact-version loading, source-bound
  context derivations, shared Portal/Channel answer evaluation, execution progress
  and cancellation diagnostics.
- Complete graph draft inspection/import, paginated SLO views, exact checkpoint
  forks, offline state integrity replay and migration preflight.
- Add registered MCP discovery and approved read-only calls, durable metadata-only
  OTLP delivery, bounded standard A2A task integration and pinned isolated
  LangGraph execution.
- Add managed image/document inputs and explicitly requested read-only diagnostics.

## Deployment

The additive schema chain ends at migration 100. Historical SQL and applied
checksums remain unchanged. Controlled capabilities require current database
state, resource authorization and separately recorded operator decisions.

## Operations

Follow [the operations guide](docs/agent-extensions.md) or
[the Chinese guide](docs/agent-extensions_zh.md). Registered integrations and
capability controls are configured independently. Live side-effect replay,
live graph migration, arbitrary framework execution and global autonomy remain
disabled. Model probes report observed support for each exact configuration;
closing a client stream does not prove that the Provider stopped its computation.
